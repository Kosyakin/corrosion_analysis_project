# Инструкция: Копирование блока приглашения

## ✅ Что было сделано

Я создал упрощенную версию HTML блока из `weddingpost.site` **без логики конструктора**, которую можно использовать в вашем ASP.NET Core приложении.

### Созданные файлы:

1. **`Pages/WeddingInvitation.cshtml`** - новая Razor страница с упрощенным блоком приглашения
2. **`wwwroot/css/wedding-invitation.css`** - стили для приглашения
3. **Обновлен `Pages/Shared/_WeddingLayout.cshtml`** - добавлены дополнительные шрифты

## 📋 Что включено в блок

### Основные секции:

1. **Приглашение** (`myinv`)
   - Заголовок "Дорогой Гость!"
   - Текст приглашения с датой
   - Изображение места проведения
   - Цитата
   - Фотографии жениха и невесты
   - Разделы: Меню, Пожелания по подаркам, Примечание, Подтверждение, Фото
   - Заключительный текст "Ждем Вас"

2. **Палитра цветов** (`palitra`)
   - Текст с просьбой придерживаться цветовой палитры
   - Цветовые кружки для демонстрации палитры

3. **Кнопка подтверждения** (`agree`)
   - Кнопка "Подтвердить" (пока без логики)

4. **Комментарии** (`comment`)
   - Ссылка для добавления сообщения (пока без логики)

5. **Опрос** (`opros`)
   - Вопросы о трансфере
   - Вопросы о пищевых предпочтениях
   - Вопросы об алкоголе
   - Вопросы о детях
   - (Секция скрыта по умолчанию: `display: none`)

## 🚀 Как использовать

### Вариант 1: Использовать как отдельную страницу

1. Перейдите на `/WeddingInvitation` в браузере
2. Страница отобразится с полным блоком приглашения

### Вариант 2: Встроить в существующую страницу

Скопируйте содержимое из `WeddingInvitation.cshtml` в вашу существующую страницу `Wedding.cshtml`:

```razor
<!-- Вставьте после секции RSVP или в любое другое место -->
@await Html.PartialAsync("WeddingInvitation")
```

Или скопируйте HTML блок напрямую в `Wedding.cshtml`.

## 📝 Что нужно настроить

### 1. Изображения
Замените ссылки на изображения на ваши собственные:

```html
<!-- Вместо -->
<img src="https://weddingpost.site/images/797060/5b78cc_20241105095155.jpg">

<!-- Используйте -->
<img src="~/img/your-image.jpg">
```

### 2. Тексты
Измените тексты на ваши данные:
- Имена жениха и невесты
- Дата свадьбы
- Место проведения
- Хештег для фото
- Дату подтверждения

### 3. Цвета палитры
Измените цвета в палитре на ваши:

```html
<div class="color" style="background: rgba(24, 26, 41, 0.21);"></div>
<!-- Замените rgba(24, 26, 41, 0.21) на ваши цвета -->
```

### 4. Показать опрос
Чтобы показать секцию опроса, измените:

```html
<!-- Было -->
<div class="container-fluid py-5 poll-section" id="poll" style="display: none;">

<!-- Станет -->
<div class="container-fluid py-5 poll-section" id="poll">
```

Когда будете готовы добавить функциональность:

## ⚠️ Важные замечания

1. **Шрифты**: Используются Google Fonts (`Great Vibes`, `Cormorant Infant`, `Philosopher`). Если нужны оригинальные шрифты (`WonderGardene`, `Zing`), их нужно будет подключить отдельно.

2. **Изображения**: Сейчас используются ссылки на оригинальный сайт. Рекомендуется загрузить изображения в `wwwroot/img/` и использовать локальные пути.

3. **Фон**: Если нужен фоновый паттерн, добавьте изображение в `wwwroot/img/` и обновите `background-image` в `.invitation-background`.
