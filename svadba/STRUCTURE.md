# Структура шаблона свадебного сайта "Jack & Rose"

## Общая информация

Шаблон построен на PHP MVC архитектуре с использованием Bootstrap 4, jQuery и различных библиотек для создания интерактивных элементов.

## Основные секции сайта (home.view.php)

### 1. **Navbar (Навигация)**
- Фиксированная навигационная панель
- Плавная прокрутка к секциям
- Адаптивное меню для мобильных устройств

### 2. **Carousel (Карусель)**
- Полноэкранная карусель с фотографиями
- Кнопка воспроизведения видео (модальное окно)
- Автоматическая прокрутка слайдов

### 3. **About (О нас)**
- Секция "Groom & Bride"
- Фотографии жениха и невесты
- Описание и социальные сети

### 4. **Story (История)**
- Таймлайн истории отношений
- 4 ключевых момента с фотографиями:
  - First Meet (Первая встреча)
  - First Date (Первое свидание)
  - Proposal (Предложение)
  - Engagement (Помолвка)

### 5. **Gallery (Галерея)**
- Карусель фотографий (Owl Carousel)
- Lightbox для полноэкранного просмотра
- 6 фотографий в галерее

### 6. **Event (События)**
- Информация о свадебных событиях:
  - The Reception (Прием)
  - Wedding Party (Свадебная вечеринка)
- Для каждого события: фото, адрес, время

### 7. **Family (Семья и друзья)**
- Секция "Groomsmen & Bridesmaid"
- Фильтрация по категориям (Isotope)
- 3 шафера и 3 подружки невесты
- Фотографии и социальные сети

### 8. **RSVP (Подтверждение присутствия)**
- Форма для подтверждения присутствия
- Поля: имя, email, количество гостей, выбор событий, сообщение

### 9. **Footer (Подвал)**
- Контактная информация
- Социальные сети
- Благодарность гостям

## Используемые технологии

### Frontend:
- **HTML5** - разметка
- **CSS3** - стилизация
- **Bootstrap 4** - адаптивная сетка и компоненты
- **jQuery** - DOM манипуляции и события
- **Font Awesome** - иконки

### Библиотеки:
- **Owl Carousel** - карусель для галереи
- **Lightbox2** - просмотр изображений в полноэкранном режиме
- **Isotope** - фильтрация и сортировка элементов
- **Easing** - плавные анимации
- **Waypoints** - триггеры при прокрутке страницы

### Backend:
- **PHP** - серверная логика
- **MVC архитектура** - разделение логики и представления
- **MySQL** (опционально) - база данных

## Функциональность JavaScript (main.js)

1. **Навигация при скролле** - показ/скрытие navbar
2. **Плавная прокрутка** - к якорным ссылкам
3. **Модальное видео** - воспроизведение YouTube видео
4. **Кнопка "Наверх"** - появление при скролле вниз
5. **Фильтрация галереи** - переключение между категориями
6. **Карусель галереи** - автоматическая прокрутка фотографий

## Что нужно добавить для ваших требований

### 1. **Карта с маршрутом**
- Интеграция Google Maps или Yandex Maps
- Отметка места проведения свадьбы
- Маршрут от точки A до точки B (если нужно)

### 2. **Расписание событий с временем**
- Расширить секцию "Event"
- Добавить детальное расписание дня:
  - Церемония: время, место, описание
  - Фотосессия: время, место
  - Банкет: время, место
  - Торт: время

### 3. **Кнопка "Добавить в календарь"**
- Генерация .ics файла (iCalendar)
- Кнопки для добавления в:
  - Google Calendar
  - Apple Calendar
  - Outlook
  - Яндекс.Календарь

### 4. **Дополнительные фотографии**
- Расширить галерею
- Добавить больше фотографий в карусель
- Возможно добавить секцию с фотографиями мест проведения

## Конфигурация

Основные настройки находятся в `app/core/config.php`:
- `HOME_ROOT` - путь к статическим ресурсам
- `ROOT` - корневой URL сайта
- `DBHOST`, `DBNAME`, `DBUSER`, `DBPASS` - настройки БД

## Как использовать

1. Установите на веб-сервер с поддержкой PHP
2. Настройте пути в `config.php`
3. Замените изображения в `public/assets/img/`
4. Отредактируйте тексты в `app/views/home.view.php`
5. Настройте форму RSVP (добавьте обработчик отправки)

## Рекомендации по кастомизации

1. **Цвета**: Измените CSS переменные или классы Bootstrap
2. **Шрифты**: Замените Google Fonts в `<head>`
3. **Изображения**: Замените все изображения в `assets/img/`
4. **Тексты**: Найдите и замените все "Lorem ipsum" тексты
5. **RSVP форма**: Добавьте обработчик на сервере или используйте Formspree/EmailJS
