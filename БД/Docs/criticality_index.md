# Индекс критичности участка трубопровода

Описание формул и переменных для возможного использования в статье или в реализации. В статье пока не используется.

---

## Остаточный ресурс по толщине (лет)

\[
R = \frac{t_{\mathrm{curr}} - t_{\min}}{V_{\mathrm{corr}}}
\]

Допустимо только при \(V_{\mathrm{corr}} > 0\).

| Переменная | Описание |
|------------|----------|
| **R** | Остаточный ресурс по толщине (лет): за сколько лет при текущей скорости коррозии толщина дойдёт от текущего значения до минимально допустимого |
| **t_curr** | Текущая измеренная толщина стенки в данной точке (мм) |
| **t_min** | Минимально допустимая толщина по проекту/нормам для данной точки (мм) |
| **V_corr** | Скорость коррозионного утонения (мм/год) |

---

## Индекс критичности K

\[
K = \frac{D/t}{R}
\]

| Переменная | Описание |
|------------|----------|
| **K** | Индекс критичности (безразмерный): чем выше K, тем выше приоритет обследования |
| **D/t** | Отношение наружного диаметра трубы к толщине стенки |
| **R** | Остаточный ресурс по толщине (лет), см. выше |

Обоснование: логика RBI (API RP 580). K объединяет геометрический фактор (D/t) и срочность исчерпания запаса по толщине (1/R).

**Применение:** ранжирование участков по риску, приоритизация обследований, разбиение на группы риска. Вычисляется после получения оценок скорости коррозии (по модели или по данным).

**Не использовать** как признак при обучении модели, предсказывающей \(V_{\mathrm{corr}}\): K зависит от целевой переменной (data leakage).
